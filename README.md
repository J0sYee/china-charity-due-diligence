# 中国公益尽调助手

`china-charity-due-diligence` 是一个用于中国大陆公益机构、基金会和公益项目尽调的 Cowork 自定义技能。它通过公开资料和官方平台线索核查登记、统一社会信用代码、公募资格、项目备案、年报或审计报告、资金用途披露和受助人保护机制，帮助捐赠人在行动前做出更审慎的判断。

## 适用场景

- 想查找中国大陆的公益项目，例如女童教育、留守儿童、罕见病、养老、助残、环保、动物保护、灾害救助等。
- 想判断某个慈善机构或基金会的公开信息是否充分。
- 想了解一笔捐款最多能追踪到机构、项目、具体用途，还是匿名受益人编号。
- 已经看到一个点对点资助对象，希望通过合格机构、学校、村委会或医院背书来评估可信度和真实资金缺口。

## 不适用场景

- 中国大陆以外注册的慈善机构。
- 税务、法律意见或合同起草。
- 实际转账、支付、填写付款信息。
- 直接核验个人求助或收集受助人的身份证、户口本、银行卡、病历、学籍材料或照片。
- 公开未成年人或弱势受助人的姓名、学校、住址、家庭细节、照片、病情或付款信息。

## 核心能力

| 能力 | 说明 |
|---|---|
| 范围识别 | 根据用户问题自动选择通用公益尽调、特定群体尽调或点对点受助对象评估。 |
| 候选搜索 | 优先使用慈善中国、国家政务服务平台、中国社会组织政务服务平台、机构官网和可信媒体报道。 |
| 合法性检查 | 核查登记状态、统一社会信用代码、公募资格、项目备案、收款主体和公开报告。 |
| 证据评分卡 | 按合法性与募捐资格、财务透明度、捐款可追踪性、项目效果证据、受助人保障机制、运营可信度六个维度评分。 |
| 可追踪性分级 | 明确捐款可追踪到 L1 机构、L2 指定项目、L3 具体用途或 L4 匿名受益人编号。 |
| 风险提示 | 标记无法核实、收款主体不一致、个人账户收款、年报缺失、过度展示未成年人等风险信号。 |
| 点对点评估 | 通过合格组织背书评估受助对象可信度，并按项目列出资金缺口和支持层级。 |

## 输出内容

默认以 Markdown 形式输出：

1. 范围和假设
2. 符合条件的项目候选清单
3. 每个候选的六维证据评分卡和置信度
4. 合法性、公募资格和项目备案核查表
5. 风险信号和缺失信息
6. 横向对比
7. 捐赠前应向机构确认的问题
8. 捐赠路径和可追踪性上限说明

在点对点资助场景中，还会追加：

1. 受助对象可信度八维表
2. 分项资金需求估算
3. 最低维持、标准支持、完整支持三档方案
4. 点对点执行结构和剩余不可证明的风险

## 安装

将本仓库作为 Cowork 自定义技能使用：

1. 下载或克隆仓库。
2. 确保技能文件夹名为 `china-charity-due-diligence`，且根目录包含 `SKILL.md`。
3. 将该文件夹放入 Cowork skills 文件夹，通常是 `Documents/Cowork/skills/`。
4. 等待约一分钟，开启新对话后输入 `/china-charity-due-diligence`，或直接用中文提出公益尽调问题。

## 使用示例

```text
帮我找中国支持农村低收入女童教育的公益项目，并比较透明度。
```

```text
这个基金会靠谱吗？我想知道它有没有公募资格和项目备案。
```

```text
我找到了一个想资助的学生，帮我判断应该通过什么机构核实，以及一年需要多少钱。
```

## 重要原则

- 有来源才写入结论；无法核实的内容必须标记为“未能核实”。
- 不把信息缺失直接推断为欺诈，只描述具体缺失证据和风险信号。
- 受助人保护优先于透明度，尤其涉及未成年人、患者、残障人士、暴力幸存者和老人。
- 不建议个人对个人直接转账；应通过已核实的慈善组织或合格背书机构执行。
- 不根据家庭成员性别或其他受保护特征筛选受助对象。
- 所有金额估算都必须来自可引用的单位成本或标记为 `[待机构确认]`。
- 本技能只做研究和比较，不替用户捐款，也不代表任何组织“绝对安全”。
